# SpendWise Personal Toolkit

A menu-driven Python application developed as the Week 8 Final Project for the Future Proof Python programming course.

## About the Project

SpendWise Personal Toolkit is a command-line application designed to help users manage personal expenses, perform calculations, organize daily tasks and plan their budgets.

## Features

- **Expense Tracker:** Record expenses, view spending history and calculate total expenditure in Kenyan Shillings (KES).
- **Calculator:** Perform addition, subtraction, multiplication and division.
- **To-Do List:** Add, view and remove daily tasks.
- **Budget Planner:** Compare recorded expenses against a personal budget.
- **Input Validation:** Handle invalid menu choices, incorrect numerical inputs and division by zero.

## How to Run

1. Clone this repository.
2. Open a terminal inside the project directory.
3. Run `python3 toolkit.py`.
4. Select a tool from the main menu.

No external Python packages are required.

## Project Limitations

Expenses and tasks are stored in memory during the current session. They are cleared when the program closes.
